# Python News Scraper

Асинхронный парсер новостных сайтов для RSS и HTML источников на Python.

## Описание

Этот модуль реализует асинхронный сбор новостей из различных источников:
- RSS-ленты (Lenta.ru, Interfax, RIA Novosti)
- HTML-страницы (BBC Russian)

Собранные данные сохраняются в локальный JSON файл для последующей обработки.

## Особенности

- **Асинхронная архитектура**: Использует asyncio и aiohttp для параллельных запросов
- **Поддержка RSS и HTML**: Универсальный парсер для разных типов источников
- **Конфигурируемость**: Легко добавлять новые источники через конфигурационный файл
- **Логирование**: Детальное логирование процесса сбора данных
- **Сохранение в JSON**: Структурированное хранение данных

## Установка

1. Убедитесь, что у вас установлен Python 3.7+
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Использование

### Запуск парсера

```bash
python main.py
```

### Конфигурация

Источники данных настраиваются в файле `config.py`:

```python
RSS_SOURCES = [
    RSSSource(
        url="https://lenta.ru/rss/news",
        name="Lenta.ru News",
        type="rss"
    ),
    # ... другие источники
]
```

### Настройки парсера

В `config.py` также доступны настройки:

```python
PARSER_CONFIG = {
    "max_concurrent_requests": 10,    # Максимальное количество одновременных запросов
    "request_timeout": 30,            # Таймаут запросов в секундах
    "user_agent": "NewsScraper/1.0",  # User-Agent для запросов
    "output_dir": "data",             # Папка для сохранения данных
    "output_filename": "news_data.json" # Имя файла с данными
}
```

## Выходные данные

Собранные данные сохраняются в формате JSON в файл `data/news_data.json`:

```json
[
  {
    "source": "Lenta.ru News",
    "source_type": "rss",
    "title": "Заголовок новости",
    "link": "https://lenta.ru/news/...",
    "description": "Описание новости...",
    "published": "Mon, 01 Jan 2024 12:00:00 +0300",
    "published_parsed": [2024, 1, 1, 9, 0, 0, 0, 1, 0],
    "authors": [],
    "categories": ["Политика"],
    "scraped_at": "2024-01-01T12:00:00.000000"
  }
]
```

## Логирование

Логи записываются в консоль с уровнем INFO. Формат логов:

```
2024-01-01 12:00:00 - __main__ - INFO - Запуск асинхронного парсера новостей
2024-01-01 12:00:01 - __main__ - INFO - Парсинг RSS: Lenta.ru News
2024-01-01 12:00:02 - __main__ - INFO - Найдено 20 статей в Lenta.ru News
```

## Расширение функциональности

### Добавление нового источника RSS

1. Добавьте новый источник в `RSS_SOURCES` в `config.py`:

```python
RSSSource(
    url="https://example.com/rss",
    name="Example News",
    type="rss"
)
```

### Добавление нового HTML парсера

1. Добавьте источник с типом "html" в `RSS_SOURCES`
2. Реализуйте соответствующую логику парсинга в методе `parse_html()` класса `AsyncNewsScraper`

## Тестирование

Для тестирования парсера можно использовать встроенные источники. Убедитесь, что у вас есть доступ к интернету для запросов к новостным сайтам.

## Примечания

- Некоторые сайты могут блокировать запросы без правильного User-Agent
- Структура HTML парсеров зависит от конкретного сайта и может потребовать адаптации
- Рекомендуется соблюдать robots.txt и условия использования сайтов
